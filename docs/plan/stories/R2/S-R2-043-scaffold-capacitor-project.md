## 3. Design notes
- `capacitor.config.ts` (exact):

```ts
import type { CapacitorConfig } from "@capacitor/cli";
const config: CapacitorConfig = {
  appId: "app.studentlifejourney",
  appName: "Student Life Journey",        // replace with the board's naming decision if it differs
  webDir: "../web/dist-native",
  server: { androidScheme: "https" },      // origin https://localhost on Android, capacitor://localhost on iOS
};
export default config;
```

  ADR-0015 names `../web/dist`; use `dist-native` so a native build never overwrites the folder the Worker deploys. Record this one deviation in the PR and in `apps/mobile/README.md`.
- Dependencies in `apps/mobile`: `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`, `@capacitor/app` — all on the **8.x** line, exact versions pinned. `apps/web` gets `@capacitor/core` 8.x only.
- Web build for shells: `"build:native": "VITE_TARGET=native vite build --outDir dist-native"`. In `vite.config.ts`, when `process.env.VITE_TARGET === "native"`: the PWA plugin is disabled (`VitePWA({ disable: true, … })` — assets are in the binary, a service worker inside a WebView adds only stale-cache bugs) and `base` stays `"/"`.
- `apps/web/src/platform/runtime.ts` (exact):

```ts
import { Capacitor } from "@capacitor/core";
export type Runtime = "web" | "ios" | "android";
export function runtime(): Runtime;        // Capacitor.getPlatform(), narrowed
export function isNative(): boolean;       // Capacitor.isNativePlatform()
```

- Lint boundary: `no-restricted-imports` forbids `@capacitor/*`, `@capgo/*`, `@aparajita/*` and `@sentry/capacitor` everywhere in `apps/web/src` except `apps/web/src/platform/**`. Screens ask `platform/*`, never Capacitor.
- `apps/mobile` scripts: `"build:web": "pnpm --filter @slj/web build:native"`, `"sync": "pnpm build:web && cap sync"`, `"open:ios": "cap open ios"`, `"open:android": "cap open android"`, `"run:android": "cap run android"`, `"typecheck": "tsc --noEmit"`.
- Native project settings: Android `minSdkVersion 26`, `versionCode 1`, `versionName "0.2.0"`; iOS deployment target 16.0, marketing version 0.2.0, build 1; display name as `appName`; portrait and landscape allowed.
- `.gitignore` additions: `apps/web/dist-native/`, `apps/mobile/android/app/build/`, `apps/mobile/android/.gradle/`, `apps/mobile/ios/App/Pods/`, `apps/mobile/ios/App/build/`, `*.jks`, `*.keystore`, `*.p8`, `apps/mobile/android/app/google-services.json`, `apps/mobile/ios/App/App/GoogleService-Info.plist`.
- CI: `pnpm typecheck`, `pnpm lint` and `pnpm test` include `@slj/mobile` (config file only). CI does **not** build native projects (ADR-0015: local builds in R2–R3). ESLint and Prettier ignore `apps/mobile/ios/**` and `apps/mobile/android/**`.
- `docs/runbooks/mobile-release.md`: prerequisites (Xcode, Android Studio, JDK 21, CocoaPods), the three commands to produce a build, where the version numbers live, and the rule "bump `versionCode` and the iOS build number for every upload".
- Edge cases: the app starts with no network → the bundled app shell renders and the existing offline indicator shows; `VITE_API_BASE_URL` missing in a native build → the build fails with a clear message (a check in `vite.config.ts`).

## 5. Acceptance criteria
- AC1: Given a clean clone with the toolchains installed, when `pnpm --filter @slj/mobile sync` runs, then it exits 0 and both native projects contain the web assets.
- AC2: Given the Android emulator (API 26 and the newest) and the iOS simulator (iOS 16 and the newest), when the app starts, then the sign-in screen renders with Tide tokens and no console error.
- AC3: Given `pnpm --filter @slj/web build && pnpm size`, then the web bundle is unchanged within 1 KB and `dist/` still contains the service worker.
- AC4: Given `dist-native/`, then it contains no `sw.js` and no web manifest registration.
- AC5 (negative): Given a file under `apps/web/src/screens/` importing `@capacitor/core`, then `pnpm lint` fails.
- AC6 (negative): Given `build:native` without `VITE_API_BASE_URL`, then the build fails with a message naming the variable.
